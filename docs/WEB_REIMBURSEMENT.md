# S4o 固定报销草稿与票据页面

入口为“我的申请 → 报销草稿”，差旅/采购申请与草稿导航均可进入。/reimbursement/drafts为本人草稿搜索分页，/reimbursement/new新建，/reimbursement/drafts/:id继续填写。页面先验证有效业务身份，所有HTTP请求仍独立鉴权；不把管理员角色当作他人草稿访问权限。

## 固定表单与来源

表单分基本信息、关联申请/独立报销、费用明细、票据附件四区，沿用公共黑白灰外壳。申请人/部门/编号/创建日期只读，由服务器确定；固定填写标题、说明、独立报销说明和备注。草稿可未填完，保存不会创建审批任务或通知。本阶段提交按钮不可用；后端已有提交能力，但提交/只读详情与通知跳转UI将在S4p接入，列表动作UI、复制重提继续分步。

费用支持0–100条增删、上下排序和五种固定类型：交通、住宿、餐饮、办公、其他。逐行填写日期、用途、金额、无票标记及原因；支持三条以上。金额预览先用现有schema规范化再以BigInt整数分合计，保留两位小数字符串，不用Number求和；无明细、金额缺失或键入无效时显示待补全，超上限提示。服务端仍为最终金额依据。

来源选择通过本人已批准的差旅/采购候选接口，支持类型、标题/编号查询和分页；只用服务器返回的候选，不允许手输来源ID。已选项跨筛选/页码保留，可取消关联；已保存来源可在新窗口打开原申请，仍由原接口鉴权。保存时重新核验资格，错误时保留输入；不修改源正文或赋予其他用户源权限。不关联时填写独立说明，草稿阶段允许暂空。查询、分页和读取失败重试按钮不是保存按钮。

PUT明确摘取固定输入字段及本单行ID，完整替换费用和来源数组，不能传回服务器总额、身份或来源摘要。新行不带ID，保存后采用返回的新ID；排序保持原ID及其票据绑定。含票据的行不能直接删除，需先显式删除全部票据，再删除费用并保存。

## 票据管理

先保存费用，再在下方选择已保存费用行；未保存的新行不能接收票据。可填写本次上传票据号码，接受JPEG/PNG/PDF实际内容，每次一份，单件10 MiB，整单共9件/50 MiB。文件仍在私有存储，不进入public，不实现OCR、号码唯一或跨单重复检测。

每条记录展示所属费用、号码、原名、类型、大小和时间。号码/归属错误需显式删除后重传，不能改绑现有记录。图片通过鉴权接口取原件为临时对象URL；PDF复用本地PDF.js逐页绘制；下载保留原字节和名称。读取失败可手动重试，不把失败当空文件。删除票据与删除整单均需明确确认，整单删除不修改关联源单。

上传/删除只更新文件列表与申请version，不保存当前表单输入、不修改无票标记。新版本用于下一次保存/文件操作；已有票据且仍标无票会提示核对，保持用户输入。无票原因不因暂时取消勾选而静默删除。号码仅随本次上传保存。

## 失败恢复

编辑入口分别读取正文和附件，version不一致不能进入编辑，须重新加载。写入同步防重入；版本冲突、非草稿、资源/行失效、附件删除保护，或网络断连/超时/5xx等不确定结果保留输入并暂停写入，不自动重放POST/PUT/DELETE。

“新窗口查看服务器记录”用于核对当前草稿，首次创建响应丢失则打开草稿列表查找；确认“丢弃本地修改并重新加载”后才丢弃输入、重新获取正文与票据。若已被其他客户端提交，草稿接口会拒绝编辑；本阶段尚无报销提交后详情Web入口。普通字段或文件格式错误可修正后再操作。401/403按既有身份约定跳转。

普通页内链接及刷新/关闭提示未保存正文；浏览器历史前进/后退不保证拦截，登录失效或整页离开可能丢失未保存输入，不提供本地持久化、自动合并或自动重试。当前界面只能保存草稿；保存成功不代表完整提交校验通过。
