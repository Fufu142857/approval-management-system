列表说明：差旅/采购/报销各有独立的全状态本人申请和任务接口。申请列表只含本人申请，按创建时间；任务 pending 仅当前实际待办、handled 仅本人已通过/驳回的任务，分别按激活/完成时间。取消任务不计已办，同一人处理两步保留两条任务。from/to 按上海日历日包含首尾，status 始终筛选申请当前状态；各接口的 type 分别只允许 travel、purchase 或 reimbursement。总数/分页/当前节点/申请版本同一 SQL 快照，跨请求可能变化；未知/重复参数返回 400。当前节点和已提交申请人姓名来自提交快照，列表不授予额外审批权。差旅类型/服务在 src/lib/travel-lists.ts、src/server/travel-lists.ts；采购对应 purchase-lists.ts，报销对应 reimbursement-lists.ts，见 API.md。报销摘要为 totalAmount/noReceiptCount，不包含来源摘要、费用行或例外原因。采购摘要另含 budgetLimit/totalAmount（精确字符串或 null）及 singleSource；零条或缺金额明细的草稿合计为 null，完整草稿舍入零是 "0.00"。不返回报价/附件/完整理由。草稿专用列表仍按更新时间，和全状态创建时间列表不同。
