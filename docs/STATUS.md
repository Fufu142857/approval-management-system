本轮复核外层设计第 7、8 页公共原型与第 10 页功能说明，执行桌面/390×844 Chrome 浏览器验收，保留黑白灰框架。尚未覆盖 Safari、Firefox、手机真机。公开 HTTPS、入口流量限制和 Docker 重建仍待部署阶段验收。资料修改、密码重置、部门增删改尚未实现。

PDF 预览使用锁定的 pdfjs-dist 6.4.299 本地 worker 逐页绘制，不依赖浏览器 PDF 插件。dev/build 自动通过 scripts/prepare-pdf.mjs 生成忽略的 public/vendor/pdfjs/版本号资源，部署须携带这些库资源；用户附件仍在私有 uploads。Node 最低 22.13，建议 24 LTS。首次保存后才能上传附件；上传/删除更新申请版本但不保存文字修改。版本冲突或不确定写入时核对服务器记录后再重新加载，不自动重放写请求。页内普通链接与刷新/关闭提示未保存内容，历史前进/后退不保证拦截，见 WEB_TRAVEL.md。

编号取舍已落定：首次创建草稿分配非空唯一 APP-序号，提交沿用；回滚/删除可产生空号。日期采用上海日历日期、首尾均计入，不记录日内时刻。草稿可缺字段，保存通过不代表提交校验通过；PUT 是完整替换，省略字段会清空，必须携带 version，详见 API.md。

固定差旅 v1 默认采用“本部门唯一有效负责人 → 全组织唯一有效财务审批人”，不按金额分支；候选不足/多名或本人审批一律拒绝，由管理员调整授权。设计未写死差旅第二级角色，S3b 已询问但未收到用户选择，按预先说明的建议值实施，不记作用户确认。已提交人员快照不可改写；同一非申请人可分别承担两步。S3c 沿用此固定规则；下一快照审批人停用/部门无效时拒绝当前批准并回滚，不换人或跳过。通知已覆盖各状态事件和本人查询/已读 API；页面、前台轮询与跳转尚未实现。没有动态模板、版本发布或可配置规则解释器。

新列表说明：申请列表只含本人申请，按创建时间；任务 pending 仅当前实际待办、handled 仅本人已通过/驳回的任务，分别按激活/完成时间。取消任务不计已办，同一人处理两步保留两条任务。from/to 按上海日历日包含首尾，status 始终筛选申请当前状态；type 当前仅 travel。总数/分页/当前节点/申请版本同一 SQL 快照，跨请求可能变化；未知/重复参数返回 400。当前节点和已提交申请人姓名来自提交快照，列表不授予额外审批权。真实类型及服务在 src/lib/travel-lists.ts、src/server/travel-lists.ts，见 API.md。

S3h 操作 UI：仅本人 pending 申请可撤回，当前实际任务人员且非本人可通过/驳回；确认框显示编号、标题、节点和意见。驳回必填，取消保留意见。成功后重新读取详情与附件；冲突/资源变化/不确定写入暂停写入并保留意见，手动重新读取后按新状态开放操作，不自动重放或自动批准下一节点。当前页面重新读取保留意见，整页刷新/离开会丢弃。

审批与撤回必须携带最新申请 version；审批还须携带实际 taskId，旧任务不能借新版本推进下一节点。已激活过任务的人员在有效身份下可以查历史，未激活即取消的未来节点没有正文权限。申请详情共享行锁与审批排他行锁保持多查询一致；后续状态写入不得绕过此锁。

通知仅凭接收人身份查询/标记；正文目标另行按 S3c 权限检查。通知标题/类别是历史事件，target.status/task.status 是当前状态；不能按旧待办标题执行审批。列表 total 按筛选统计，unreadCount 是本人全量未读数。POST 已读只收 {}，重复和并发调用保留首次时间。

附件只允许本人草稿上传/删除，每次递增申请 version；提交前验证文件完整性，提交后冻结。列表/下载与正文授权一致，管理员和未来 blocked 节点无特权。限额按 10 MiB/件、9 件与 50 MiB/申请，详情见 API.md。默认私有目录 uploads/attachments（可用 ATTACHMENT_STORAGE_DIR 配置），不能放 public；异常回收用 `pnpm attachments:gc`，必须与当前数据库配套。上传/删除锁顺序为组织 → 存储 72004 共享锁 → 申请；回收独占 72004 后确认数据库引用，不能直接删不确定提交结果对应文件。测试已隔离文件目录，不得改为开发 uploads。

S2c 的自定外观已由 S2d 纠正；当前身份、差旅草稿/列表/详情/审批确认没有各自独立原型，沿用设计第 7、8 页公共视觉框架，不宣称逐像素一致。S5 停止全项目代码修改的边界继续有效。
