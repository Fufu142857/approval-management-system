# S3i 通知页面与前台轮询

本阶段接入已有 S3d API，不改变 HTTP 契约、审批事务或数据库迁移。仅固定差旅事件已落地，工作台统计、复制重提、小程序和后台推送仍待后续阶段；S5 人工边界不变。

## 页面与操作

- /notifications：仅本人通知，全部/未读/已读筛选，默认每页 10 条；state/page/pageSize 保存于 URL，服务端严格校验，非法/重复参数提供重置入口，越界空页可回第一页。
- /notifications/:id：通知标题/类别/收到时间/首次已读时间，关联申请与原任务当前状态，显式已读与“查看申请详情”。页面先做业务身份检查，资源 GET 再独立验证所有权。
- 有效账号的侧栏开放“通知中心”并显示本人全部未读数；未读数失败显示“—”和不可用说明，不把失败当零。

读取列表、进入通知详情或申请详情不会自动标记已读；需点击“标记已读”，POST 只发 {}。写入中按钮禁用并用引用互斥，成功或非鉴权失败后回查通知与计数，不乐观减少计数，不自动重放 POST。响应丢失时显示需核对的反馈；后端幂等保留首次阅读时间。写入不影响申请、待办和日志。

title/kind 描述历史事件，target.status/task.status 描述本次查询的当前状态。旧“新待办”也可能已完成或取消，通知没有审批按钮。只在当前返回 target.type=travel 时用其 id 映射到固定差旅详情页，不把 API 地址当导航 URL；target=null 不显示申请跳转。详情 GET 失败时隐藏跳转，正文页面和接口仍重新鉴权，再按最新 version/taskId 决定动作。

通知列表 total 按当前筛选，unreadCount 是本人全量；进入通知列表/详情会立即刷新侧栏计数；侧栏独立计数和列表可能处于不同时点，不强行合成同一快照。新事件可能使偏移分页位移，刷新/返回第一页核对。不会因轮询把用户强制带回第一页。

## 生命周期与错误

use-foreground-resource.ts 在可见页面立即读取，每次请求完成后间隔 30 秒再读，同一个读取器不重叠；15 秒请求超时。隐藏时取消请求并清除定时器，恢复可见立即读取。查询切换、重试及组件卸载取消旧读取，迟到结果不能覆盖新查询；重试 GET 不触发写操作。

离开通知页面停止列表/详情轮询；侧栏计数在有效登录工作区仍可更新。退出开始通过上下文暂停通知读取并取消在途 GET；退出失败恢复。会话 401 停止并跳登录；页面通知 GET 的 403 停止并进入账号反馈。全局计数遇 403 清除旧数据、停止本读取器且显示不可用，不在账号页造成重定向循环；恢复权限后可重新加载账号。原有身份会话检查仍独立运行，不将其称为通知轮询。

网络/5xx 错误显示明确提示和重试，保留上次成功数据与时间并标注旧数据；初次失败不显示假空态。下一次可见轮询可自动恢复。已读过程中仍可能发生页面离开；取消客户端等待不代表服务器撤销写入，返回后按 GET 核对，幂等契约保持首次时间。没有 WebSocket、Service Worker 推送或关闭页面后的触达。

## 外观与测试

查看外层设计第 7 页公共框架与第 10 页功能说明；通知页没有独立原型，沿用黑白灰侧栏、顶栏、白卡片、轻分隔线和按钮，不宣称逐像素复刻。通知以正文列表呈现，手机竖排，不使长标题撑宽页面。原型渲染只留仓库外临时目录，截图在忽略的 tmp/screenshots/notifications-*.png。

六组新增 Chrome 用例在 tests/e2e/notifications.spec.ts：事件/已读/历史状态/跳转；分页筛选/URL/移动外观；真实审批后自动更新、隐藏/恢复/离页/退出；读失败和写响应丢失回查；匿名/跨人/空目标/会话失效；慢请求/取消旧筛选/退出等待。轮询测试推进浏览器时钟并派发可见性事件；目标 null 分支使用拦截响应，真实后端权限与持久化仍由既有集成/HTTP 测试覆盖。具体结果见 STATUS 与 DEVELOPMENT_LOG；不等同于 Safari/Firefox、手机真机、小程序、后台推送或 Docker 验收。
