# 固定业务查询统计 Web（S4t）

入口为工作区侧栏“查询统计”，路由 `/statistics`。服务端页面在 `src/app/(workspace)/statistics/page.tsx`，客户端固定组件在 `src/components/statistics-panel.tsx`。复用 S4s `GET /api/statistics`，没有新 API、数据库迁移或依赖；金额/时间/授权契约见 [STATISTICS.md](STATISTICS.md)。工作台和全局搜索仍未开放。

## 使用与口径

默认本人申请、全部固定业务、不限部门与提交日期。可筛选申请所属部门、采购/差旅/报销、提交起止日期；当前部门负责人另可选“本部门申请”，部门选项固定为自己的确认部门。普通员工、管理员、财务和企业负责人没有隐含部门汇总权。全部部门只扩大本人历史申请的部门条件，不扩大申请人范围。

修改控件后点击“查询”，有效条件写入 URL，刷新、前进/后退能恢复已应用条件；结果标题另显示服务端实际范围、部门、类型和日期。“刷新统计”重新读取当前已应用条件，不提交未查询的控件改动。重置返回默认本人范围。历史/不可用部门 UUID 保留为明确选项，不悄悄改成全部部门；严格拒绝重复、未知、空值和非法参数，提供重置入口。

数量卡片分别展示当前范围已提交申请和本人实际待办，状态横条按申请总数展示审批中/已通过/已驳回/已撤回，并提供可读文字数量，不依赖颜色。本人待办始终是本人实际当前任务，独立于申请范围；部门、类型、提交日期仍作用于关联申请。零申请不代表零待办，两个指标单独显示。

采购明细批准总额、差旅批准预算、报销批准费用各有独立卡片，分别列出四状态和本人待办。不提供跨类型金额合计。十进制字符串只插入千位分隔符，不转 Number；缺失金额显示“无法完整合计”及缺失单数，无已批数据为 0.00。日期统一使用申请提交日的上海日历边界，不含草稿；当前状态不等于截止日期的历史状态。汇总不授权读取正文或附件。

## 加载与恢复

读取中隐藏旧结果，加载提示和区域 aria-busy 对应当前请求。每次筛选或刷新使用独立请求键，离页/更换查询中止旧请求，迟到响应不覆盖新结果；15 秒超时。失败清除旧统计，不显示成零或继续冒充最新数据，允许手动刷新。统计权限不足在本页解释并提供本人入口；401 返回登录，账号或部门失效沿用业务状态页。读取不自动标记通知已读，也不执行审批写入。

本页按进入、查询或手动刷新读取；不宣称后台推送或自动实时统计。部门/角色变更会由已有服务撤销会话，下一请求重新鉴权；客户端下拉选项不是权限依据。
